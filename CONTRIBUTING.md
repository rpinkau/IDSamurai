# Contributing to IDSamurai

Thank you for your interest in IDSamurai! 

**Please note: This is a solo project and I am currently NOT accepting any code contributions or Pull Requests.**

Because I intend to remain the sole copyright holder and author of this codebase, I cannot accept external code modifications. Any submitted Pull Requests will be politely declined and closed.

### How you can still help:
* **Bug Reports:** Feel free to open an Issue if you encounter a bug.
* **Feature Requests:** You can open an Issue to suggest new features.
* **Forking:** Under the terms of the GPLv3 License, you are absolutely free to fork this repository and modify the code for your own projects!

Thank you for understanding and respecting the solo nature of this repository.
